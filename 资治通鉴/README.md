# 资治通鉴 · 精选决策课

从《资治通鉴》里抽出仍能用在今天的决策课：少复述年表，多讲**当时怎么决策、为何翻车、今天怎么用**。

气质靠近钱穆《中国历代政治得失》，文风求口语、略幽默，不戏说。

## 第一辑读什么

1. **信息与决策** — 听不见真话，再聪明也白搭  
2. **改革为何难** — 完美方案如何把自己改死  
3. **中层与执行** — 政策很好，落地很歪  
4. **危机中的领导力** — 止损、士气、信誉当场兑现  
5. **权力交接与接班** — 权杖怎么递，暗物质怎么交  
6. **系统崩溃与亡国前夜** — 小裂缝如何滚成大崩盘  

每章结构固定：**史例对照 → 规律 → 组织怎么用 → 个人怎么用 → 章末带走**。假定读者已有初高中历史脉络。

## 摘一句

> 英不英明，取决于你肯不肯改自己的通道和赏罚。书改不了那一步。

## 怎么用

- 想建立整体感：按目录顺序读  
- 工作里正卡住：直接跳对应主题（例如推动变革读第 2 章，团队执行歪了读第 3 章）  
- 史实出处见书末「史例与通鉴卷次索引」；正文是压缩转写，精读请回《资治通鉴》通行校本
